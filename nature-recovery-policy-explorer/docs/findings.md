# Current Findings

## Overview

The current canonical publish covers `204,652` hexes across England and allows
the same geography to be compared under five different policy scenarios.

## Main Points

- `6,580` hexes remain in the stable core across every scenario.
- `32,429` hexes are contested, meaning their relative strength changes more materially when the policy lens changes.
- Every scenario retains a national top-decile set of roughly `20,476` to `20,478` hexes and a top `1%` set of `2,057` hexes.
- The explorer is most useful where rank spread is high, because those places are more sensitive to policy trade-offs.
- The current tile contract is already narrow enough for a practical browser-facing layer: shared IDs, flags, best-rank fields, and one percentile field per scenario.

## Use

This file is intended as a short portfolio-style note alongside the app rather
than a full analytical report.
